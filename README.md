# ☕ Java — Primeiros Passos: Lógica de Programação e Algoritmos

Repositório criado para registrar meus estudos, exercícios e práticas desenvolvidos durante o curso **Java: Primeiros Passos — Lógica de Programação e Algoritmos**, realizado na Udemy.

O projeto tem como objetivo aprofundar meus conhecimentos em **Java, lógica de programação e algoritmos**, fortalecendo fundamentos importantes para o desenvolvimento de aplicações e para minha evolução como desenvolvedor.

## 📚 Conteúdos estudados

Durante o curso, são abordados conceitos fundamentais de programação, incluindo:

* Sintaxe e estrutura básica do Java
* Variáveis e tipos de dados
* Entrada e saída de dados
* Operadores aritméticos, relacionais e lógicos
* Estruturas condicionais
* Estruturas de repetição
* Vetores e matrizes
* Funções e métodos
* Lógica de programação
* Algoritmos
* Resolução de problemas utilizando programação

Além de reforçar conceitos de lógica e algoritmos, o projeto faz parte da minha busca contínua por aprimoramento técnico e expansão da minha stack de desenvolvimento.
